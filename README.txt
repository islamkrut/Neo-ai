Neo-ai — сайт с локальными моделями

1. Загрузите index.html и sw.js в корень HTTPS-сайта (например, GitHub Pages или Netlify).
2. Откройте сайт в Chrome и загрузите выбранную модель с интернетом.
3. Дождитесь завершения загрузки. В последующих посещениях файлы модели обычно берутся из кэша браузера.
4. Для офлайн-проверки откройте сайт ещё раз онлайн, затем выключите интернет и обновите страницу.

Важные ограничения:
- Модели хранятся в браузерном кэше, который браузер может очистить при нехватке места. Гарантии вечного хранения нет.
- Библиотека Transformers.js использует дополнительные WASM-файлы; для надёжного офлайна убедитесь, что сайт полностью загружался онлайн.
- MyMemory-перевод и Википедия не работают без интернета.
- Сайт на file:// не поддерживает Service Worker: нужен HTTPS или localhost.
- Модели Qwen могут сильно тормозить на компьютере с 4 ГБ ОЗУ.
